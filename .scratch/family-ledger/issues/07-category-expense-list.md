# 07 — 分類消費清單

**Status:** ready-for-agent

**Blocked by:** 04 — 分析頁

## Problem Statement

分析頁的分類明細只告訴成員「這個分類這段期間花了多少」，看不到錢具體花在哪些東西上。想知道「這個月食物為什麼這麼高」，只能回記帳頁一天一天點開找。

## Solution

點分類明細的某一列，從底部滑出該分類在目前統計區間的**分類消費清單**：依日期由早到晚逐筆列出日期、內容、金額。唯讀，只供檢視。定位是分類明細的下鑽，不是通用篩選。

## User Stories

1. As a 成員, I want 點分類明細的某一列，打開該分類在目前統計區間的分類消費清單, so that 知道這個分類的錢具體花在哪些東西上。
2. As a 成員, I want 分類明細每一列尾端有灰色「›」並有按壓回饋, so that 一看就知道可以點進去。
3. As a 成員, I want 只有分類明細列表可點、甜甜圈圖不可點, so that 不會誤觸難以點準的小片。
4. As a 成員, I want 清單以底部 sheet 呈現、上方露出分析頁, so that 知道自己還在分析頁，關掉就回到原處。
5. As a 成員, I want 點 × 或點背景關閉清單, so that 和紀錄表單的操作一致。
6. As a 成員, I want 清單很長時在 sheet 內捲動, so that 分析頁的捲動位置不受影響。
7. As a 成員, I want 標題顯示分類圖示與名稱, so that 確認看的是哪個分類。
8. As a 成員, I want 標題下一行灰字顯示「區間標題 · N 筆 · $金額」, so that 確認期間，且數字與分類明細那一列一致。
9. As a 成員, I want 清單依日期由早到晚、同日依記錄先後排列, so that 像流水帳從頭讀到尾，和選中日清單的順序規則一致。
10. As a 成員, I want 月、年區間每列顯示「10/3」格式的日期, so that 知道每筆是哪天，年份已在標題不重複。
11. As a 成員, I want 日區間每列不顯示日期, so that 不出現整排相同的日期。
12. As a 成員, I want 同一天的多筆消費不分組、每列各自顯示日期, so that 筆數不多時畫面不被小標切碎。
13. As a 成員, I want 每列顯示內容與金額, so that 知道每筆花在什麼、花多少。
14. As a 成員, I want 沒填內容的消費以灰字顯示分類名稱, so that 和記帳頁看到的文字一致，也看得出這筆沒寫內容。
15. As a 成員, I want 清單沒有總計列與百分比, so that 重點放在逐筆明細，總額已在標題。
16. As a 成員, I want 點清單中的消費沒有任何動作, so that 清單單純用來看；要修改就回記帳頁。
17. As a 成員, I want 清單開著時 App 回到前景重撈資料後清單跟著更新, so that 不會看到另一位成員已刪除的消費。
18. As a 成員, I want 跨過午夜、分析頁錨點跟著換到新的今天時清單也跟著換, so that 清單永遠對應目前的統計區間。
19. As a 成員, I want 清單變成 0 筆時不自動關閉、改顯示「這段期間沒有這個分類的消費。」, so that 畫面不會突然消失。

## Implementation Decisions

- **領域模組**新增 `categoryExpenses(expenses, { granularity, anchor, category })`：回傳該分類在統計區間內的消費，依 date、再依 created_at 由早到晚排序（明確排序，不依賴輸入順序）。
- 統計區間 → 日期前綴的計算從 `periodStats` 抽成模組內共用的 helper，保證清單的筆數與金額和分類明細一致。
- **日期模組**新增短日期格式「M/D」（例如 `10/3`）。
- 新增唯讀 sheet 元件，props 為分類、清單紀錄、區間標題、是否顯示日期；外觀與開關行為比照紀錄表單（fixed 背景、底部貼齊、× 與點背景關閉）。
- 分析頁只多一個狀態：目前打開的分類（null 表示關閉）。清單用 computed 由「消費紀錄 + 粒度 + 錨點 + 分類」算出，因此重撈資料與跨日跟隨都自動反映。
- 分類明細的每一列改為按鈕，列尾加灰色「›」。
- 不改 schema、API，無 migration。

## Testing Decisions

- 好的測試只驗證外部行為：給消費陣列與區間，斷言回傳的紀錄與順序，不碰內部 helper。
- 只測領域模組，在既有 ledger 測試檔新增「分類消費清單」一組，比照「統計區間」那組的寫法與測資風格。
- 案例：只回傳該分類、日/月/年區間邊界（不含前一月最後一天、去年 12/31）、同日依 created_at、不依賴輸入順序、空結果、筆數金額與 `periodStats` 的分類彙總一致。
- Vue 元件不寫測試，以 dev server preview 手動驗證。

## Out of Scope

- 通用搜尋與多條件篩選
- 在清單中編輯、刪除消費
- 甜甜圈圖切片可點
- 清單內依日期分組、總計列、百分比
